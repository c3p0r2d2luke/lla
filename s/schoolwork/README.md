# Schoolwork pages

This folder holds standalone HTML pages and small browser-based projects. You
can open an individual `.html` file in a browser, or serve the parent `s/`
folder over HTTP to try the pages in a more typical website setup.

Most pages are self-contained, so there's no separate build step for this
folder. Some projects may rely on external services or resources; check the
page itself for any setup notes. Have fun exploring! 📚
